# Areaprop

A real estate web platform inspired by Zonaprop, developed as an academic project.

## Overview

Areaprop is a full-featured real estate web application designed to simplify property searching, listing, and direct communication. The platform supports distinct user roles, allowing both individual clients and real estate agencies (*inmobiliarias*) to register, publish listings, and manage property inquiries efficiently.

### Key Features

* **Multi-Role Authentication:** Dedicated accounts and dashboards for clients and real estate agencies.
* **Property Exploration:** Search and filter residential and commercial properties by location, price, and amenities.
* **Listing Management:** Agencies and owners can publish, update, and manage property portfolios.
* **Direct Inquiries:** Seamless communication between potential buyers/renters and listing managers.
